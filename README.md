# Colab → Hermes Kit

Два готовых ноутбука для **Google Colab** (бесплатный GPU), которые превращают Colab в твои личные серверы:

1. **LLM-сервер** — открытая нейросеть (Qwen2.5 7B/14B/32B) с OpenAI-совместимым API. Подключается к Hermes как обычный провайдер модели.
2. **ComfyUI** — генератор картинок (SDXL / Juggernaut XL) + апскейлер. Hermes может рисовать через него («сгенерируй картинку: …»).

## Как запускать (каждый раз)

1. Открой ноутбук по ссылке.
2. Меню **Среда выполнения → Сменить тип среды выполнения → T4 GPU** → Сохранить.
3. Меню **Среда выполнения → Выполнить все** (Ctrl+F9). На предупреждение «не от Google» — **Run anyway**.
4. Дождись в конце блока `СКОПИРУЙ ЭТО И ПРИШЛИ В ЧАТ HERMES` — скопируй его целиком.
5. **Пришли блок в чат Hermes** (или выполни локально: `bash tools/colab-wire.sh` → вставь блок → Ctrl-D).

Первый запуск: LLM 5–10 мин, ComfyUI 6–12 мин (качаются модели). Повторный запуск в новой сессии — то же самое: диск Colab обнуляется.

## Что делает подключение к Hermes

- LLM: создаётся/обновляется провайдер `colab` в `~/.hermes/config.yaml`; в чате Hermes можно писать `/model custom:colab:colab-llm` или звать `hermes chat --provider colab`.
- Картинки: адрес ComfyUI сохраняется в `~/.hermes/colab/COMFY_URL.txt` и используется скиллом `comfyui` (`run_workflow.py --host <URL>`).

## Честные ограничения бесплатной Colab

- Сессия живёт до ~12 часов (часто меньше). После смерти — «Выполнить все» заново, **ссылка будет новая**.
- GPU не гарантирован: квоты и очереди. Иногда проще запустить в другой день.
- Одновременно один GPU-ноутбук: либо LLM, либо картинки.
- Ноутбук должен работать, пока он нужен (вкладку можно свернуть, но не закрывать).
- Всё, что скачано в `/content`, исчезает с сессией — это нормально.
- Для персонального использования; не публикуй ссылки из блоков.

## FAQ

| Проблема | Решение |
|---|---|
| «Нет GPU» | Среда выполнения → Сменить тип → T4 GPU |
| vLLM не завёлся | Ячейка «АЛЬТЕРНАТИВА: Ollama» в конце ноутбука (или Перезапустить сессию и заново) |
| В логе «поднялся с 32768» | YaRN-расширение не сработало → Перезапустить сессию и «Выполнить все»; если повторяется — Ollama-ячейка |
| Hermes: «context window below the minimum 64,000» | Сервер поднялся с контекстом < 64k — см. пункт выше; основной моделью в Hermes проходит только 65536 |
| Ссылка отвалилась | Сессия умерла → запусти заново, пришли новый блок |
| Colab «недоступен» из твоей сети | Включи VPN, перезапусти сессию |
| Хочу модель побольше | `MODEL_PRESET = "14b"` / `"32b"` в ячейке 1 (нужен платный GPU) |
